# Changelog

## v0.1.0 - 2026-10-12

- First release: `web_search`, `web_fetch` and `research` tools on the local keyless DonSeTch engine,
  implementing the Laravel AI tool contract on any provider.
- Measured defaults: 3000ms search deadline, 6000ms batched fetch deadline, container-resolved
  settings, an honest no-binary contract, and a framework-free test suite with a live probe.
